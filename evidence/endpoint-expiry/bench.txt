(-140 is the code the STM32 partition returns for "session ended by the clock" (docs/endpoint-expiry.md); the STM32
prover prints PSA codes, the RW612's protocol code prints "ERR pq expired". Attestation still answers after the end; the gateway provisions a new session at its next
cycle.)

Clock rates: the STM32's RTC runs on its internal RC oscillator (LSI) at 0.941 s per gateway second on both boards,
inside the 1/16 margin, so the endpoint never ends a session before the gateway does; a session can then last up to
3825/0.941 = about 4065 s of real time. The RW612's secure SysTick (clk=ref) runs at 1.000.
